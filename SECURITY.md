# Security Policy for @kaito-tokyo/KaitoTokyo-SimpleJsonReader

This project is provided “as is,” without warranty. Although we make reasonable efforts to address reported vulnerabilities, we cannot guarantee security updates or support. We recommend using the latest release to receive available security fixes.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it to us privately. Please do not publicly disclose the vulnerability before we have had a reasonable opportunity to investigate and address it. We will try to fix vulnerabilities in a timely manner.
